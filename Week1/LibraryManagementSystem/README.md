# Library Management System

## Overview

Library Management System 

## Features

* Add Book
* Add User
* Display Books
* Display Users
* Search Book by Title
* Issue Book
* Return Book


## Project Structure

* Main.java
* Book.java
* User.java
* Library.java
* LibraryException.java

## How to Run

Compile the project:

```bash
javac *.java
```

Run the application:

```bash
java Main
```
